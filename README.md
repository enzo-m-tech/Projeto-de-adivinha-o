 🎲 Jogo de Adivinhação (Random Guess Game)
Este projeto é um jogo simples de adivinhação feito em Python usando o módulo random.
O computador escolhe um número aleatório dentro de um intervalo definido, e o jogador tenta adivinhar qual é esse número!
🧠 Como Funciona
O programa escolhe um número aleatório dentro de um intervalo (ex: 1 a 10).
O usuário tenta adivinhar digitando um palpite.
Se acertar: o programa avisa que o número está correto.
Se errar: informa que não acertou.
🧩 Tecnologias Usadas
Python 3
Módulo random
🎯 Objetivo do Projeto
Treinar lógica básica
Praticar uso de entrada de dados
Praticar condicionais
Usar o módulo random
